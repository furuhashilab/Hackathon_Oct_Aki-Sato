# 発表メモ（1分）

1. **（10秒）I：問題**
   京都の天然砥石は丹波帯の特定の地層（砥石型珪質頁岩＝Type Ⅰ の最下部）から採れる。論文には砥石山と地層を描いた地質図があるけど、紙の上の絵なので実際の地図と重ねられない。

2. **（15秒）参考発表と新技術：Maplat**
   FOSS4G Hiroshima の「10 Years of Maplat」で知った **Maplat** を使った。絵地図を歪めずに、対応点で実際の地図と結びつける技術。論文の図は縮尺と注記がずれているので、対応点を必ず通る Maplat の変換が合う。

3. **（15秒）M：方法**
   論文の図から、色で地層の帯、記号で砥石山を自動抽出 → 産総研の20万分の1地質図のチャートと一番重なる位置を探して対応点に → Maplat の TIN で実座標へ。

4. **（10秒）R：結果（デモ）**
   見つかった縮尺は論文の縮尺バーとぴったり一致。左で論文の図／20万分の1／地理院を切り替えると、同じ砥石山が各図のどこにあるか分かる。砥石山 21 か所は **全部Ⅰ型地層群**、Ⅱ型には 0。

5. **（10秒）D：考察**
   「砥石層はⅠ型地層群の最下部」という記述と合う。一方、最初の雑な位置合わせでは「チャートの縁に集まる」と見えたのが、正しく合わせると消えた。位置合わせが結論を左右するので、Maplat で一次資料に戻って確かめられることが大事。
